# May December Men's Club

Business-owned repository for the May December Men's Club Phase 0 pilot.

Authoritative repository: `may-december-club/may-december-mens-club`.

The repository is owned under the May December Club GitHub organization. Phase 0 work is conducted under the approved pilot scope and uses business-controlled repository governance and non-Production Staging infrastructure.

## Phase 0 goals

- Establish the Rails application foundation and engineering controls.
- Implement the Registration / Pending Member vertical slice.
- Implement a representative higher-risk account-state authorization slice with authoritative server-side enforcement.
- Produce automated positive and negative authorization coverage.
- Measure human effort, AI-assisted implementation, review, rework, defects, and accepted-output efficiency.
